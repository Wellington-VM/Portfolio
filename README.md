# Portfólio - Wellington Vinicius

Este projeto foi desenvolvido com o objetivo de apresentar minhas habilidades, tecnologias e projetos desenvolvidos.

O portfólio reúne informações sobre minhas competências técnicas, projetos acadêmicos e formas de contato, servindo como uma vitrine profissional para recrutadores e colaboradores.

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- AOS (Animate On Scroll)
- Animate.css

## Funcionalidades

- Design responsivo para desktop e dispositivos móveis
- Navegação intuitiva entre seções
- Apresentação de projetos através de modais interativos
- Animações de entrada e transição
- Download de currículo
- Área de contato

## Objetivo

O principal objetivo deste projeto é demonstrar minhas competências em desenvolvimento Front-end, design de interfaces e organização de projetos web, aplicando boas práticas de responsividade, usabilidade e experiência do usuário.
